# 哈爾濱家族行程比較（內部預覽）

靜態頁，供家人比較當地團路線、價錢與待確認事項。出行口徑為三名成人、兩間房、航班自理，比較時以七座車為準。頁面以比較總表、相對價格與差異重點為主，各團每日行程放在其後。請勿公開轉發報價連結。

目前整理月月、瑤瑤、西西、小秦（星漠游）、小徐（中際國旅）、阿華（AAA自由行高端品質遊・阿華領隊）的報價。頁面可用「5天4夜／7天6夜」切換分開比較，預設先看 5天4夜。7天6夜目前已收到阿華結算價 ¥11,400（3,800×3，5座、預估）、小徐三人合計 ¥14,172（4,724×3，GL8），以及月月 12月3–9日行程（總價仍待報）。西西另有 6天5晚趣玩・長白，放在「其他長度」，不與五日或七日線混比。GitHub Pages 開啟後即可瀏覽。
