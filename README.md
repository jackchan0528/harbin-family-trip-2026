# 哈爾濱家族行程比較（內部預覽）

靜態頁，供家人比較當地團路線、價錢與待確認事項。家人目前計劃是 6天6晚哈爾濱－亞布力－雪鄉：三名成人、一間家庭房、航班自理；12月3日抵達，住至 12月8日當晚，12月9日自行退房；含接機、不含送機（除非報價另行寫明）；第6天自行安排。指定口徑為桔子水晶／望山／雪山雪、七座奔馳、兩人滑雪＋一人不滑雪。頁面以比較總表、相對價格與差異重點為主，各團每日行程放在其後。請勿公開轉發報價連結。
